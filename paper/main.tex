\begin{abstract}
Event-based infrared focal planes are arriving (DARPA FENCE; a 2026 event-based MWIR demonstration; uncooled Poisson-bolometer LWIR pixels), yet no public thermal event data---real or synthetic---exists. We present the first open-source pipeline converting thermal-infrared video to event streams with sensor-physics-aware simulation: pivot-centered AGC de-flickering, temporal interpolation audited for the thermal domain, and three simulation modes including a Poisson-bolometer switching model. We release STED, a synthetic thermal event detection benchmark with ground-truth physics parameters, and convert real UAV thermal video (HIT-UAV) as a real-data anchor. Experiments cover interpolation fidelity, event statistics, simulator parameter sensitivity, and detection across frame/event/fusion channels with scene slicing. All findings are framed as simulator-conditional pre-hardware algorithm studies.
\end{abstract}
