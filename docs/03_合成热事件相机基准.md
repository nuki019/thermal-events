# 项目三：合成"热事件相机"基准 — 热红外视频到事件流的转换管线与检测基准

**一句话主张**：事件式红外硬件正在到来（DARPA FENCE；雷神 2026 年 4 月首次实机演示事件式 MWIR 相机；事件式 LWIR 测辐射热计器件论文），但**全世界还没有任何公开的热事件数据**——真实的或合成的都没有（已核实）。本项目用事件相机仿真器把公开热红外视频转换为合成热事件流，发布转换管线与首个热事件检测基准，在硬件普及前的算法真空期插旗。

**状态**：调研完成（2026-07-26）。新颖性成立但窗口不长（DVS-PedX 已把"转换公开数据集并发布"模板推向主流）。预计 10–16 周至投稿。这是四个项目中上限最高、风险也最高的一个。

---

## 1. 研究问题与贡献主张

**RQ1**：现有事件仿真器（为可见光 DVS 设计）在热红外视频上的适用性与失真模式是什么？
**RQ2**：合成热事件流上的目标检测相比热帧检测，在运动、低对比度、数据率上的得失如何？
**RQ3**：热传感器物理（微测辐射热计时间常数、NETD、AGC）应如何注入仿真参数？

**贡献主张**：
- C1：首个热红外→事件的开源转换管线（含热特有的 AGC 归一化与传感器物理参数化）；
- C2：首个（合成）热事件检测基准：热帧 vs 热事件 vs 融合，多场景切片（昼/夜/运动/小目标）；
- C3：仿真器×参数的保真度研究（用 EQS 指标 + 插帧质量验证），明确"仿真条件性"边界；
- C4：数据发布：许可允许范围内发布转换数据集（HIT-UAV 为 CC BY 4.0 保底），其余以"代码+一键重建"模式发布。

## 2. 相关工作与定位

### 2.1 新颖性核查结论（关键）

已逐一排查（截至 2026-07-26）：**不存在公开热事件数据集**。最接近的都不是：
- EVIF (CVPR 2024) [1]：**可见光** DAVIS346 事件 + 热帧配对；合成部分是 KAIST **可见光**通道过 ESIM——事件从来不是热的；
- DVS-PedX (Scientific Data 2026) [2]：v2e 转换 JAAD **RGB** 行车视频——正是本项目的方法论先例，但明确限于可见光；
- SEVD [3]：CARLA 合成**可见光**多视角事件；
- Raytheon FENCE MWIR 演示（2026-04）[4]：硬件演示，**无数据发布**；Purdue 泊松测辐射热计 [5]：单像素器件+16×16 仿真，无数据集；
- CVPR EventVision 2025 workshop 接收论文清单：**零篇**热/红外相关 [6]；PBVS 热成像 workshop 无事件赛道。

### 2.2 硬件趋势（timing argument 的证据链）

- DARPA FENCE 计划：事件式红外焦平面阵列 + 嵌入式神经形态处理，<1.5 W [7]；
- Raytheon 事件式 MWIR 相机实机演示（地面车辆/飞机/实弹场景，2026-04-13 新闻稿）[4]；
- "Uncooled Poisson Bolometer for High-Speed Event-Based LWIR Thermal Imaging"（Purdue, arXiv 2026-01）：自旋电子随机开关 LWIR 像素，~1 ns 翻转，NETD ~100 mK，0.2 µW/像素 [5]；
- "Neural bolometers"（Phys. Rev. Applied 2026）[8]；事件式成像光谱用于高超声速观测（Aerosp. Sci. Technol. 2025）[9]；
- 专利 WO2022010456A1 "Event-based thermal camera system" 存在 [10]（不妨碍发表，写作时注意措辞）。

### 2.3 仿真器（方法工具箱）

| 仿真器 | 特点 | 用途 |
|---|---|---|
| ESIM (CoRL 2018) [11] | 自适应采样，渲染器耦合 | 经典引用 |
| vid2e (CVPR 2020) [12] | "回收已标注视频数据集"模板 | 本项目的直接模板 |
| **v2e (CVPRW 2021) [13]** | 噪声模型全（光感带宽/阈值失配/漏事件/散粒噪声）；需 SuperSloMo 插帧 | 主力工具 |
| DVS-Voltmeter (ECCV 2022) [14] | 布朗运动像素随机过程模型 | 对照仿真器 |
| ADV2E (2024) [15] | 模拟像素电路滤波，截止频率与源帧率解耦 | 热时间常数建模入口 |
| PECS (ECCV 2024) [16] | 物理光学 + **多光谱渲染** | 论证红外适配的引用 |
| V2CE (ICRA 2024) [17] | 学习式转换，自动时间戳 | 对照 |
| V2V (2025) [18] | 直接输出体素，存储小 150× | 发布形态选项 |
| Raw2Event (2025) [19] | 把非 DVS 传感器包装成事件相机 | 讨论章引用 |

### 2.4 检测基线

事件侧：RED (NeurIPS 2020) [20]、**RVT (CVPR 2023) [21]**（Gen1 47.2 mAP，<12 ms/帧@T4，现代标准基线）、SAST (CVPR 2024) [22]、SSM (CVPR 2024) [23]（跨频率泛化——对源帧率不一的转换数据特别相关）、LEOD (CVPR 2024) [24]（标签稀疏——转换数据标签受源帧率限制，直接适用）、EvRT-DETR (ICCV 2025) [25]。
热帧侧：FLIR v2 上 YOLOv8n mAP@50 ≈ 0.517（9 类，MS-YOLO 论文报告）[26]；TIR-YOLO-ADAS [27]。

### 2.5 仿真-真实差距（审稿主攻点的防线）

- Stoffregen et al., ECCV 2020 [28]：仿真统计必须匹配目标传感器，否则迁移degrade；
- **EQS 事件质量分 (CVPRW 2025) [29]**：评估合成事件真实感的现成指标——直接用于 C3；
- "Thermal is Always Wild" (CVPR 2026) [30]：记录了热视频 AGC 帧间光度漂移——会产生虚假全局事件，是热特有的、必须处理的失真源（我们的 AGC 归一化模块因此成为贡献而非工程细节）。

## 4. 方法

### 4.1 转换管线（C1）

1. **预处理**：14→8 bit 规范化审计；**AGC 去抖**——对全局增益漂移做时域平滑/直方图匹配（回应 [30]），消除虚假全局事件；
2. **插帧**：SuperSloMo（v2e 内置，可见光灰度训练）vs RIFE vs FILM，在热视频上以留出帧重建 PSNR/SSIM 评测并选优（本身是 C3 的一部分——"可见光插帧器在热视频上行不行"没人回答过）；
3. **事件生成**：v2e 主力 + DVS-Voltmeter / ADV2E 对照；
4. **热物理参数化**：对比度阈值 ↔ NETD（~100 mK [5]）换算；微测辐射热计时间常数（~ms 级）→ ADV2E 风格低通截止；泊松开关统计（[5]）作为噪声模型变体；
5. **输出**：AEDAT/npz 事件流 + 30 Hz 事件帧 + 体素（V2V 格式选项）；标签沿用源标注（按最近帧对齐，LEOD 处理稀疏标签）。

### 4.2 基准任务（C2）

- 检测：行人/车辆（KAIST、FLIR 类映射）；协议参照 Prophesee 工具箱惯例（COCO mAP，小框过滤，跳过序列头 0.5 s）[35]；
- 三通道对比：热帧 YOLOv8 / 事件 RVT / 早期融合（事件帧+热帧堆叠）；
- 场景切片：昼/夜、相机运动强弱、目标尺寸、AGC 扰动段。

### 4.3 保真度评估（C3）

- EQS [29] 评分各仿真器×参数组合；
- 插帧质量（热域 PSNR/SSIM）；
- 事件统计对照（事件率分布、极性平衡、空间稀疏性）vs Gen1/1Mpx 真实数据的统计包络；
- 敏感性：检测 mAP 对阈值/噪声参数的偏导——结论以"参数带"而非单点给出。

## 6. 评估与成功标准

**指标**：COCO mAP / mAP@50（检测）；EQS、事件统计距离（保真）；事件率、存储比（效率）；各场景切片增量。

**成功标准**：
- 底线：管线+基准+保真度研究成立，事件通道在**夜间/强运动切片**上相对热帧有可测优势（哪怕整体 mAP 略低）——即可发 workshop/数据集论文；
- 理想：融合通道全面超过热帧基线 ≥2 mAP，主张"事件式红外的算法价值先于硬件到位"；
- 注意：**不主张**合成结果等于真实传感器性能；所有结论明示"simulator-conditional"（[28] 的教训写进 limitations）。

**目标发表**：
- 会议：ICRA 2027（截稿约 2026-09，赶得上 E0–E4 精简版）；WACV 2027 后轮次；CVPR EventVision workshop 为双年制，2025 已过 → 瞄准 2027 届；
- 数据集论文：Scientific Data（DVS-PedX 同刊先例 [2]）或 NeurIPS 2027 Datasets & Benchmarks；
- 期刊备选：IEEE TITS。

**风险与对策**：
- FLIR 许可不允许再分发 → 代码重建模式 + HIT-UAV 保底（已规划进 E0/E6）；
- 插帧器在热域失真 → E1 先行验证，失真本身可写成发现；
- 无真实热事件数据可验证 → 定位为"pre-hardware algorithm study"，引 [4][5][7] 硬件趋势与 [29] 保真度界定；雷神/FENCE 数据一旦公开，本基准是现成对标物（先发优势）；
- 被抢发 → DVS-PedX 模板已主流化，建议 E2 完成即挂 arXiv 技术报告占位。
